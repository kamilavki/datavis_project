# European Energy Transition: 1990–2024

A comprehensive data visualization project exploring the shift from fossil fuels to renewable energy across Europe, analyzing the relationship between GDP, CO2 emissions, and energy infrastructure.

## Project Links
* **Project Site:** [WordPress Site](https://datavisualization34.wordpress.com/#)
* **Tableau Dashboard:** [Public Tableau Dashboard](https://public.tableau.com/app/profile/aleks.rzesny/viz/data_vis_project1_17784224331850/Dashboard1?publish=yes) (Also accessible via the project website)

## Key Deliverables

* **[dataviz_report.pdf](dataviz_report.pdf)**: The final comprehensive report detailing our methodology, findings, and ethical considerations.
* **[final_notebook.ipynb](final_notebook.ipynb)**: The primary technical document containing all Python source code for data cleaning, Exploratory Data Analysis (EDA), and figure generation.
* **[energy_portraits.html](energy_portraits.html)**: Our unique visualization component – a series of concentric "tree-ring" portraits showing the decade-by-decade energy evolution of European nations.
* **[co2_calculator.html](co2_calculator.html)**: An interactive JavaScript-based tool for carbon calculation.

## AI Use Statement
This project utilized AI tools for code optimization, data structuring, and descriptive assistance. A detailed **AI Use Appendix** documenting the specific prompts and ethical oversight applied during this process is included within the final report.

## Built With
* **Python** (Pandas, Matplotlib, Seaborn) for data processing and EDA.
* **JavaScript** for interactive components and custom visualizations.
* **Tableau** for geospatial and comparative dashboarding.
